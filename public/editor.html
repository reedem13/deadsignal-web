How to edit a map

  1. Open. This page loads the map the game is playing. If nobody has saved one, that is the Relay Yard (dock water, cooling basin, south-yard spawns).
  2. Edit. Click a type on the left, then click the ground to place it. Click a piece to select it and drag to move it. Yellow squares on the edges change the size. Rotate, Duplicate and Delete are on the top bar. The panel on the right is that piece: height, facing, the item in a locker, a guard's waypoints.
  3. Undo if a drag goes wrong. Right-drag orbits the camera. Scroll zooms. Left-drag on empty ground pans. North is up in the angled view.
  4. Download keeps a JSON file. Open brings a file back. Save on server stores it here without changing the live mission.
  5. Playtest opens the game on this map, on this computer, with Solo ticked. A partner joining that tab would not see your edits.
  6. Use in the game saves the map and makes Host / Join play it. Original map puts the Relay Yard back for everyone. The yard is still in the game if the server forgets a save.

Low crates can be climbed without a marker. A climb wall is the marked spot where two players boost. A cargo net climbs like a ladder. Guards on a deck need walk areas or they step off.
